# Security

Please report security issues in the Extremis MCP server, its OAuth sign-in or Extremis itself privately to **support@extremis.online** with "Security" in the subject. Do not open a public issue.

Include what you found, how to reproduce it and what an attacker could do with it. We aim to reply within a few working days.

Please test only against your own workspace, and do not access, change or delete other people's data.
